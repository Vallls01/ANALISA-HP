# Cek Kerusakan HP

## Deskripsi
Banyak orang hp nya rusak tapi tidak tahu bagian mana yang bermasalah, jadi website ini membantu memperkirakan penyebabnya dari gejala yang dialami.

## Target Pengguna
Pemilik hp yang awam soal kerusakan.

## Link Website
https://vallls01.github.io/ANALISA-HP/

## Fitur dan Halaman
- Beranda: Kotak pilihan bagian HP yang ingin dicek.
- Cek Kerusakan: Pilih gejala, lalu muncul perkiraan penyebab, saran awal, dan tingkat keseriusannya.
- Daftar Kerusakan: Galeri contoh kasus yang pernah ditangani.
- Tentang: Tentang saya.
- Kontak: Form keluhan yang membuka WhatsApp.

## Cara Menggunakan
1. [Buka website]
2. Pilih bagian hp yang bermasalah di beranda.
3. Pilih gejala yang paling mirip, lalu klik tombolnya.
4. Baca hasilnya, dan hubungi lewat halaman kontak bila perlu.

## Teknologi yang Dipakai
- HTML, CSS, dan JavaScript.
- VS Code sebagai editor, Live Server untuk uji coba.
- GitHub dan GitHub Pages untuk penyimpanan dan penayangan.
- Lighthouse untuk uji performa dan aksesibilitas.

## Keputusan Desain
- Background saya menggunakan warna putih karena supaya font jelas dan enak dibaca.
- Warna font saya buat warna biru supaya kontras dengan background dan bisa dibaca.
- Saya memberi opsi dengan kotak-kotak supaya terkesan tiap kerusakan benar-benar berbeda.

## Aksesibilitas dan Performa
Teks alternatif pada foto (alt), label pada form, tampilan yang menyesuaikan layar hp, dan foto yang dikecilkan.

## Kendala dan Solusi
- Kendala 1 : Kontak tidak bisa langsung terhubung ke Whatsapp, lalu saya merombak ulang dan dibantu AI
- Kendala 2 : Menu layanan ada yang error, saya teliti lagi dan saya memanggil ulang.

## Catatan dan Keterbatasan
- Hasil di halaman Cek Kerusakan hanya perkiraan awal, bukan diagnosis pasti. Penyebab sebenarnya baru diketahui setelah hp diperiksa langsung.
- Data gejala masih terbatas pada enam bagian hp.
